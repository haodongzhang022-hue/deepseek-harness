# V3 collaboration

V3 development uses the shared release-control pipeline. Read [`AI_RELEASE_COLLABORATION_RULES.md`](AI_RELEASE_COLLABORATION_RULES.md) and [`RELEASE_CONTROL_PIPELINE.md`](RELEASE_CONTROL_PIPELINE.md) before testing or requesting release validation.

Test agents use ports 8009–8016 and register their Harness session, capability, and heartbeat. Ports 8008, 8027, and 8028 remain reserved for their existing owners and explicit release decisions.
